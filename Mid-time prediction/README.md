## Часть 1: Модель машинного обучения на ежедневных данных

### Постановка задачи

Ваша задача – попытаться построить модель, которая будет способна предсказать
направление движения актива на рынке на следующий день на основании
извлеченных вами признаков. На выбор можно взять либо биржевые инструменты,
либо криптовалюты.

В качестве входных данных модель будет использовать временные ряды активов.
Чтобы было удобнее с ними работать, мы ограничим интервалы времени, доступные
на вход модели 30-ю днями (см. схему препроцессинга данных). Используя значения
цен на этих интервалах, вам предстоит извлечь различные признаки. Одной из групп
признаков должны стать результаты кластерного анализа временных рядов. Например,
вы можете использовать метку кластера и любые другие статистики, которые вы
посчитаете нужным, в качестве входных данных.

В качестве целевой переменной вам необходимо для каждого 30-дневного интервала
взять значения цены на следующий день и посчитать, в какую сторону она изменилась
по сравнению с предыдущим днем. В зависимости от волатильности ваших временных
рядов, выберите некоторый процент изменения цены, в интервале которого вы будете
считать цену актива стабильной, например, от -5% до +5%.
### Этапы выполнения задачи

1. **Сбор данных:** Собрать временные ряды финансовых данных (среднюю цену
   или цену закрытия) с частотой один час за последние 180 дней для 100+
   различных тикеров акций или криптовалют . Если в выбранном API 180 дней с
   часовой частотой не доступны, выбрать максимально доступный диапазон.
2. **Формирование окон:** Разделить данные на окна длительностью 30 дней (720 точек) с использованием скользящего окна с дневной частотой. Отложить часть данных для тестирования.
3. **Кластеризация окон:** Для полученных окон на тренировочной выборке
   построить модели кластеризации временных рядов и выбрать одну, которую вы
   будете использовать в дальнейшем для извлечения признаков
4. **Создание признаков:** Извлечь значимые признаки из каждого окна, используя статистические методы и информацию о кластерах.
5. **Разметка:** Определить целевую переменную на основе тренда на следующий день (рост, снижение или стабильность).
6. **Обучение модели:** Построить и обучить модель классификации для
   прогнозирования меток (рост, снижение, стабильность) на основе извлеченных
   признаков.
7. **Оценка модели:** Оценить точность модели на тестовых данных.

### Необходимые инструменты

1. **Python для работы с API финансовых данных:**
    - Для акций используйте [Yahoo Finance API](https://pypi.org/project/yfinance/):
      ```python
      import yfinance as yf
      data = yf.download('AAPL', period='6mo', interval='1h')
      ```
    - Для криптовалют можно использовать [CoinGecko](https://www.coingecko.com/en/api) (данные с часовым интервалом доступны только за последние 90 дней):
      ```python
      from pycoingecko import CoinGeckoAPI
      cg = CoinGeckoAPI()
      data = cg.get_coin_market_chart_by_id(id='bitcoin', vs_currency='usd', days=90)
      ```

2. **Машинное обучение:** Опыт работы с тренировочными и тестовыми данными, кластеризацией, классификацией и оценкой качества моделей.
3. **Извлечение признаков из временных рядов:** [GitHub](https://github.com/DmitrySerg/otus-public/tree/master/OpenLessons/ts-feature-extraction), [YouTube](https://www.youtube.com/watch?v=miy0KusjPa4&ab_channel=OTUS%D0%9E%D0%BD%D0%BB%D0%B0%D0%B9%D0%BD-%D0%BE%D0%B1%D1%80%D0%B0%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5)
